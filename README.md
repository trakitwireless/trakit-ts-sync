# trakit-ww

This library provides a full suite of tools to keep a local copy of objects from Trak-iT's APIs in-sync. Other Trak-iT API libraries are available on GitHub. https://github.com/trakitwireless

### Prerequisites

The `trakit-ts.objects` package is required as since this library sends requests to the APIs. The `trakit-ts.commands` package is required as most Response classes will contain an object from that library.
